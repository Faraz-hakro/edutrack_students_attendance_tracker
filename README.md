# 🎓 EduTrack – Students Attendance & Student ID Tracker

> **Web Technology  Project**  
> *Developed by Faraz Hussain*

EduTrack is an interactive, professional, single-page web application engineered for managing student attendance, departmental percentage ratios, and digital ID card verification. Designed specifically for academic tracking at **Shaikh Ayaz University**, it combines dynamic UI components with real-time statistics.

---

## ✨ Key Features

- **📊 Departmental Analytics Dashboard:** Dynamic metrics showing total students, present/absent ratios, average attendance percentages, and department-level progress indicators.
- **🪪 Live Digital Student ID Card Card:** Interactive ID Card viewer that dynamically updates and displays student information (Roll No, Department, Status, Contact) upon row selection or registration.
- **📝 Attendance Management Engine:** Dynamic table supporting instant Present/Absent toggles, quick record deletion, and auto-updated attendance statistics.
- **🔍 Instant Roll No & Name Search:** Live search filter supporting queries by Student Name, ID Card/Roll Number (`SAU-2026-CS-042`), or Department.
- **➕ Student Enrollment Modal:** Clean pop-up form allowing admins to register new students dynamically into the active roster.
- **🎨 Modern Vibrant Palette:** Built with a custom Indigo, Emerald, Rose, and Amber CSS color system.

---

## 🛠️ Tech Stack

- **HTML5:** Dynamic form handling, modal templates, and semantic layout.
- **CSS3:** Custom UI themes, Flexbox, CSS Grid, animated CSS badges, and CSS Variables.
- **JavaScript (ES6):** State updates, real-time table manipulation, dynamic student ID card renderers, and attendance calculation formulas.
- **FontAwesome v6:** Comprehensive educational and administrative icon suite.
